## Linguagem e Framework
* **Linguagem:** Java (JDK 17+)
* **Framework:** Spring Boot (Spring Web + Thymeleaf)
* **Persistência:** Ficheiros JSON (arquitetura sem banco de dados, utilizando Jackson ObjectMapper)

## Comandos para Executar
Para correr a aplicação, certifique-se de que tem o Java e o Maven instalados, e execute o seguinte comando na raiz do projeto:
```bash
mvn spring-boot:run
